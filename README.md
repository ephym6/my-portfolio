# Ephy Macharia: portfolio

My personal site: **[ephy-macharia.vercel.app](https://ephy-macharia.vercel.app/)**

I'm a software engineer and Computer Science student at Strathmore University in Nairobi,
working on full-stack web apps and machine learning. The site covers my projects
(including a case study of PlantID, an on-device plant identifier for Android), my
experience, skills and CV.

## Built with

- [React 19](https://react.dev/) and [React Router](https://reactrouter.com/)
- [Vite](https://vite.dev/)
- [Tailwind CSS v4](https://tailwindcss.com/)
- [React Icons](https://react-icons.github.io/react-icons/)
- Hosted on [Vercel](https://vercel.com/)

## Running it locally

```bash
cd react-portfolio
npm install
npm run dev
```

See [`react-portfolio/README.md`](react-portfolio/README.md) for how the content is organised.
